# 무엇을 검증할 것인가

이 저장소가 반복해서 낸 결함은 "검증을 안 해서"가 아니다. **검증은 했고, 통과했고,
제품은 틀려 있었다.** 2026-08-04~05 하루에만 일곱 번:

| 통과한 검사 | 실제 결함 |
|---|---|
| FTS 열 **이름**이 런타임과 같다 | 내용이 달랐다 — `just eval-search`가 출하품을 4.0점 낮게 쟀다 |
| 하네스가 같은 코드를 부른다 | 배선이 달랐다 — 질의 확장이 eval에만 붙고 앱에는 안 붙었다 |
| `POST /markdown`이 `<video>`를 남긴다 | README 렌더러는 지운다 — 히어로가 빈 문단으로 나갔다 |
| `cover-cases.json`이 무늬 파라미터를 고정한다 | 두 클라이언트가 그 파라미터로 **네 가지 다른 그림**을 그렸다 |
| `ios-i18n-check`가 키 집합 대칭을 확인한다 | 집합이라 중복이 사라졌다 — Swift가 실행 즉시 트랩, 공유 확장이 매 저장마다 죽었다 |
| iOS 골든에 "웹의 값" 숫자가 적혀 있다 | 웹에는 그걸 확인하는 테스트가 없었다 — 절반의 도메인에서 갈라져 있었다 |
| `just eval`이 상위 3을 채점한다 | 앱은 5를 붙였다 — 두 칸이 채점 밖에서 화면으로 나갔다 |

## 하나의 규칙

**사람이 실제로 만나는 산출물을 검사하라. 그것을 만드는 것도, 그것을 닮은 것도 아니라.**

일곱 개 전부 대리물을 검증했고, **닮았다는 것이 믿은 이유**였다. 열 이름이 같으니 내용도
같겠지. 마크다운을 렌더하니 README도 같겠지. 파라미터가 같으니 그림도 같겠지. 대리물은
언제나 더 편하고 더 빠르고 대개는 맞다 — 틀릴 때만 조용하다.

## 따라 나오는 셋

**입력이 아니라 출력을 비교한다.** 두 구현이 같아야 한다면 같은 입력을 준다는 것을 확인하지
말고 **같은 것을 내놓는지** 확인한다. `cover-cases.json`(파라미터)이 통과하는 동안
`cover-ops.json`(도형)이 잡아냈다. 그 차이가 전부다.

**게이트는 실패시켜 보기 전까지 게이트가 아니다.** 중복 키 검사는 통과했고 앱은 죽었다 —
집합으로 모으는 코드가 중복을 지웠기 때문이다. 새 게이트를 만들면 **일부러 깨뜨려** 빨개지는
것을 보고 나서 믿는다. 이 세션에서 변이 검증한 게이트는 전부 버텼고, 안 한 것만 통과했다.

**측정이 좋아지면 배선을 의심한다.** 숫자가 움직였는데 화면이 안 바뀌었으면 하네스만 고친
것이다. 검색 확장이 정확히 그랬다 — eval에서 좋아지고 앱에는 안 붙어 있었다.

## 이 저장소의 이음매

각각 한 번씩 물었다. 대리물로 확인하고 넘어가지 말 것.

- **하네스 ↔ 런타임** — `search_eval.go`/`eval.go`가 `internal/store`·`internal/tagger`와
  같은 것을 색인하고 같은 상수를 쓰는가. `TestEvalHarnessIndexesLikeRuntime`이 지금 이걸 본다
- **eval ↔ 앱 배선** — 새 동작을 `internal/app`에도 붙였는가. 붙였다면 도는 서버에서 확인
- **웹 ↔ iOS** — 값이 아니라 **결과물**을 공유 픽스처로 비교(`testdata/*.json`).
  `just i18n-cross-check`, `CoverGeometryTests`
- **`POST /markdown` ↔ README 렌더러** — 다른 파이프라인이다. 라이브로 확인:
  `curl -H "Accept: application/vnd.github.html" .../repos/OWNER/REPO/readme`
- **빌드 ↔ 화면** — `.claude/rules/ui-verification.md`. 이 저장소가 낸 모든 UI 결함이
  깨끗하게 컴파일됐다
- **200 ↔ 사람이 보는 것** — 배포가 200을 준다고 페이지가 맞는 것은 아니다.
  실제로 열어 볼 것

## 언제 이 비용을 치르지 않아도 되는가

전부에 적용하면 아무것도 못 만든다. 이 규칙이 값을 하는 곳은 **틀려도 조용한** 자리다 —
숫자가 그럴듯하게 나오거나, 화면이 그럴듯하게 그려지거나, 검사가 초록인 채로 틀리는 곳.
크래시하거나 컴파일이 깨지는 것은 스스로 말하므로 대리물로 확인해도 된다.
